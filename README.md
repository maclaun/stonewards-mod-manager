# StoneWards Mod Manager

Официальный менеджер модификаций для игры **StoneWards** (Early Access, 2026).

## Возможности
- 🛠️ Автоматическое определение папки с игрой StoneWards.
- 📦 Установка BepInEx 5 в один клик.
- 🌐 Автоматическая загрузка доступных модов напрямую из GitHub-релизного API.
- 🔘 Удобное включение и отключение модов тумблерами (переименование `.dll.disabled`).
- 🚀 Запуск игры прямо из менеджера.
- 📦 **Self-Contained Executable**: Не требует предварительно установленного .NET Runtime!
